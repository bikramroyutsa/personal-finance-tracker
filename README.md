# Personal Finance Tracker

A beautiful, local-first Flutter application to effortlessly track your personal expenses, loans, and debts. 

## Features

- 💸 **Expense Tracking**: Log and categorize your daily expenses.
- 🤝 **Debt & Loan Management**: Keep track of money you've lent out or borrowed, with easy settlement toggles.
- 📊 **Beautiful Visualizations**: Clean UI and interactive charts to visualize where your money goes.
- 📁 **CSV Import/Export**: Easily import your existing financial history from CSV, or back it up whenever you need.
- 📈 **Excel Export**: Export your data into beautifully formatted `.xlsx` files with tabs for each month and rows for each day.
- 🌙 **Dark Mode**: Automatically adapts to your system theme.
- 🔒 **Privacy First**: Fully local. All data is saved on your device using SQLite.

## Getting Started

1. Make sure you have Flutter installed.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the app on your connected device or emulator.
